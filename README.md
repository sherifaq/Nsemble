# Nsemble - Premium Digital Catalog

A static, premium, highly responsive digital catalog built strictly with HTML5, CSS3, and Vanilla JavaScript.
No frameworks, No build step, No dependencies.

## Usage
1. Open `index.html` in any browser.
2. The site uses relative paths and functions perfectly locally or hosted on GitHub Pages.
3. Assets like `logo.svg` and `favicon.ico` should be placed in `/assets`. Image folders are structured in the tree but utilize CSS placeholders until actual assets are provided to keep performance scores flawless.

## Features
- Pure Vanilla JS catalog filtering and rendering.
- Automated WhatsApp ordering links passing product parameters.
- SEO optimized with meta schemas.
